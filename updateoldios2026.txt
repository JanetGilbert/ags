current Xcode can't open). Remove the app delegate object from each one by editing
the XML directly, and send the edited files back.

In each file:
1. Find the delegate's object number: in flattenedProperties, the "N.CustomClassName"
   key whose value is the delegate class (e.g. agsAppDelegate). N is the object number.
2. Find its internal id: the IBObjectRecord with objectID N gives it in
   <reference key="object" ref="ID"/>.
3. Delete:
   - the <object class="IBUICustomObject" id="ID"> block in IBDocument.RootObjects
   - every IBConnectionRecord whose source or destination ref is ID
   - the IBObjectRecord with objectID N

     at the same position in dict.values (the lists must stay the same length)
4. Leave the IBDocument.Classes class descriptions alone.
5. Verify: the file parses as XML, ID no longer appears anywhere, and sortedKeys and
   values have equal counts. Show me the diff.

Afterwards, main.m must pass NSStringFromClass([MyAppDelegate class]) as the last
argument of UIApplicationMain, since the xib no longer creates the delegate.
